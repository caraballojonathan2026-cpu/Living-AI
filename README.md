# Living AI

## Una misión: preservar lo que importa.

Living AI es un proyecto de inteligencia artificial personal centrado en Alma.

Objetivos:

- Funcionar localmente.
- Tener memoria persistente.
- Aprender del usuario.
- Organizar conocimiento.
- Funcionar sin depender constantemente de Internet.

Estado actual:

Fase 2 - Preparación del entorno.

Plataforma objetivo:

- Android

Modelo inicial:

- Qwen 3B GGUF
